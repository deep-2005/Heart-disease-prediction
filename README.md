# ❤️ Heart Disease Prediction Using Machine Learning

## 📌 Project Overview

This project focuses on analyzing a heart disease dataset and building machine learning models to predict whether a person is likely to have heart disease.

The project includes **Exploratory Data Analysis (EDA)**, data preprocessing, feature encoding, feature scaling, machine learning model training, and model evaluation.

Several classification algorithms are implemented and compared based on **Accuracy** and **F1 Score**.

---

## 🎯 Objectives

* Analyze the heart disease dataset.
* Perform Exploratory Data Analysis (EDA).
* Identify missing and invalid values.
* Clean and preprocess the dataset.
* Convert categorical variables into numerical values.
* Scale the features using StandardScaler.
* Train multiple machine learning classification models.
* Compare model performance using Accuracy and F1 Score.
* Save the trained Logistic Regression model and preprocessing files for future use.

---

## 📊 Dataset

The project uses a heart disease dataset containing medical and demographic attributes.

### Main Features

| Feature         | Description            |
| --------------- | ---------------------- |
| `Age`           | Age of the patient     |
| `Sex`           | Sex of the patient     |
| `ChestPainType` | Type of chest pain     |
| `RestingBP`     | Resting blood pressure |
| `Cholesterol`   | Cholesterol level      |
|                 |                        |
